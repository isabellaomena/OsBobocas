## Sobre o projeto

O **Os Bobocas** é um projeto de desenvolvimento web que reúne os portfólios pessoais de seis integrantes em um único site. A página inicial (`index.html`) funciona como um menu: cada cartão leva à página individual de um participante.

Cada página tem sua própria identidade visual e apresenta informações pessoais, hobbies, curiosidades, lugares e outros interesses.

## Como visualizar localmente

1. Clique em **Code → Download ZIP** na página do repositório ou clone com Git:

   ```bash
   git clone https://github.com/isabellaomena/OsBobocas.git
   ```

2. Abra a pasta `OsBobocas`.
3. Abra o arquivo **`index.html`** no navegador.
4. Escolha um dos seis integrantes na página inicial.

**Importante:** mantenha as pastas `paginas/` e `imagens/` junto do `index.html`, sem alterar os nomes, para que links e imagens funcionem corretamente.

## Publicação com GitHub Pages

O repositório está organizado para publicação pelo GitHub Pages a partir da raiz da branch `main`.

1. Abra **Settings → Pages** no GitHub.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch **`main`** e a pasta **`/(root)`**.
4. Salve as configurações.

Após a publicação, o endereço padrão do site é:

**https://isabellaomena.github.io/OsBobocas/**

> O link estará disponível quando o GitHub Pages estiver ativado e a implantação for concluída.
